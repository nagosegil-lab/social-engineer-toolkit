# Module: `src/core/dictionaries.py`

Import path: `src.core.dictionaries`

## Module docstring

Python lists used for quick conversion of user input
to strings used by the toolkit

## Basic import example

```python
from src.core.dictionaries import <symbol>
# <symbol> can be a function or class from this module
```

## Functions

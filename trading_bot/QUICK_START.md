# 🚀 הפעלה מהירה - בוט מסחר MT5 + AI

## התקנה מהירה (5 דקות)

### 1. הפעל את סקריפט ההתקנה
```bash
python quick_start.py
```

### 2. הפעל את הבוט
```bash
python start_bot.py
```

### 3. פתח דפדפן
נווט ל: `http://localhost:5000`

### כפתורים עיקריים:
- **התחל/עצור** - הפעלה ועצירה של הבוט

- **רווח/הפסד** - רווח או הפסד נוכחי
- **פוזיציות פתוחות** - מספר הפוזיציות הפעילות
- **AI פעיל** - סטטוס הבינה המלאכותית

---

## ⚙️ הגדרה ראשונית

### 1. ערוך את קובץ .env
```env
MT5_LOGIN=12345678
MT5_PASSWORD=your_password
MT5_SERVER=YourBroker-Demo
MT5_PATH=C:\\Program Files\\MetaTrader 5\\terminal64.exe
```

### 2. התאם פרמטרי מסחר
```env
SYMBOL=EURUSD          # זוג מטבע
LOT_SIZE=0.01          # גודל פוזיציה
MAX_POSITIONS=3        # מקסימום פוזיציות
STOP_LOSS_PIPS=50      # הפסד מקסימלי
```

---

## 🔧 פתרון בעיות נפוצות

### בעיה: "MT5 not found"
**פתרון:** עדכן את `MT5_PATH` בקובץ .env

### בעיה: "Connection failed"
**פתרון:** ודא ש-MetaTrader 5 פתוח ופעיל

### בעיה: "Packages not found"
**פתרון:** הרץ `pip install -r requirements.txt`

## 🚀 התקנה מהירה

### שלב 1: הורדת הקבצים
```bash
# שכפול הפרויקט
git clone <repository-url>
cd mobile-trading-bot

# הרצת סקריפט ההתקנה
python3 setup_bot.py
```

### שלב 2: הגדרת הסביבה
```bash
# העתקת קובץ ההגדרות
cp .env.example .env

# עריכת ההגדרות
nano .env  # או כל עורך טקסט אחר
```

### שלב 3: הגדרת MT5
```bash
# ב-.env קובץ, הגדר:
MT5_SERVER=your-broker-server
MT5_LOGIN=your_account_number
MT5_PASSWORD=your_password
```

### שלב 4: הגדרת Telegram (אופציונלי)
1. צור בוט חדש ב-Telegram דרך @BotFather
2. קבל את ה-Token
3. הוסף את הפרטים ל-.env:
```bash
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

### שלב 5: הפעלה
```bash
# Linux/Mac
./start_bot.sh

# Windows
start_bot.bat

# או עם Docker
docker-compose up
```

## 📱 שימוש מהטלפון

### גישה לממשק
1. פתח דפדפן בטלפון
2. גש לכתובת: `http://your-server-ip:8080`
3. התחבר עם הסיסמה: `trading123` (שנה אותה!)

### תכונות בממשק הנייד
- **דשבורד ראשי** - מצב הבוט, יתרה, רווח/הפסד
- **פוזיציות פתוחות** - רשימת כל העסקאות הפעילות
- **הגדרות** - שינוי פרמטרי סיכון ומסחר
- **בדיקת התראות** - בדיקת מערכת ההתראות

## ⚙️ הגדרות מתקדמות

### פרמטרי סיכון
```python
# אחוז סיכון מקסימלי לעסקה
MAX_RISK_PER_TRADE = 0.02  # 2%

# הפסד יומי מקסימלי
MAX_DAILY_LOSS = 0.05  # 5%

# מספר פוזיציות מקסימלי
MAX_OPEN_POSITIONS = 5
```

### הגדרות AI
```python
# סוג מודל
AI_MODEL_TYPE = "lstm"  # או "cnn"

# תקופת היסטוריה לניתוח
AI_LOOKBACK_PERIOD = 60

# רמת ביטחון מינימלית
AI_CONFIDENCE_THRESHOLD = 0.7
```

### זוגות מטבעות
```python
# זוגות המטבעות למסחר
TRADING_SYMBOLS = "EURUSD,GBPUSD,USDJPY,AUDUSD"
```
